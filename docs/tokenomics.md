## How to read any claim you see

Anything describing a Developr token, including supplies, unlock schedules or "allocations," that does not match this file is **unverified**. Before acting on a claim:

1. Check that this file and the site's contract slot both state an address.
2. Compare the **full** contract string on the **correct network** (Robinhood Chain, ID 4663). A ticker or a social handle proves nothing.
3. Check that the address was announced through a channel listed in the README as stated. At the moment none are.

## If a token is ever introduced

The project commits to publishing the following here **before** any launch, in this order:

1. The full contract address and network.
2. Total supply and whether it can change.
3. The complete allocation table, with who controls each part and any lock terms.
4. What the token does, and what it does not do.
5. Audit or review status of the contract.

Until those five items exist in this file, treat the project as having no token.
