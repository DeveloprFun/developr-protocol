# Roadmap

Phases describe intent, not promises. No dates are given because none are committed. Checkboxes show what actually exists.

## Phase 0: Foundation (current)

- [x] Brand mark and palette sampled from supplied assets
- [x] Public site with live chain numbers (value locked, chain head, gas, daily volume, deepest pairs)
- [x] Lookup bar for token contracts and pool identifiers
- [x] Contract-address slot and social icons that stay inert until real values exist
- [x] Automated checks for layout, copy originality, palette provenance and data parsing
- [ ] Project repository made public
- [ ] Official social account announced

## Phase 1: Readable pools

- [ ] Plain-language summaries for pools that carry known behaviors
- [ ] Shareable page per pool identifier
- [ ] Public JSON feed of the dashboard figures
- [ ] Machine-readable guide for automated tools

## Phase 2: The designer

- [ ] Confirm the final set of rack slots and their exact behavior
- [ ] Designer that previews a rack's rules and worst-case outcomes
- [ ] Reference implementations for each slot, with tests
- [ ] Independent review of every reference implementation

## Phase 3: Deploy

- [ ] Single-step deployment of a reviewed rack
- [ ] Post-deploy monitoring on the dashboard
- [ ] Documentation for third-party slot authors

## Phase 4: Open ecosystem

- [ ] Submission process for community-written slots
- [ ] Review criteria published and versioned
- [ ] Partner integrations

## Change policy

Items move only when the work is verifiable. A box gets checked in the same change that delivers the work.
